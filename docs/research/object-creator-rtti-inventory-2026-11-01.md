## What this establishes

The executable contains RTTI names for 286 `CGameObjectCreator<T>` template instantiations. This is a useful class/creator discovery index for the Object and Asset Workbench. It is evidence of creator-related type metadata in the binary; by itself it does **not** prove that every class is enabled in the current build, that a particular asset can instantiate it, or that a safe callable constructor/world-registration ABI is known. Keep each class name as a candidate until its resource requirements and call path are traced.

The names are grouped heuristically by substring for browsing. Categories are disjoint only to avoid duplicate display; they are not inheritance classifications.

Selected inheritance chains were separately traced through RTTI class-hierarchy descriptors in [object-type-hierarchies-2026-11-01.md](object-type-hierarchies-2026-11-01.md).
