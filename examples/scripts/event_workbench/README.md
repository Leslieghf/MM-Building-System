# Event Workbench

This package adds a read-only **Events** tab to the native workbench. Load it with `script load event_workbench`.

Its inventory distinguishes confirmed special-camera action registrations and shared registry/publisher behavior from unresolved payload contracts and unrelated RTTI leads. It does not subscribe to or dispatch game events. The package uses the workbench host API and copied script-panel model; its content is assembled from the ordered `sources` list in `manifest.toml`.

See the [event inventory research note](../../../docs/research/event-workbench-inventory.md) and [scripting guide](../../../docs/scripting.md) for the evidence and package contract.
